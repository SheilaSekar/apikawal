# Daftar screenshot proposal

Ambil screenshot browser dengan data demo dan badge DATA SIMULASI terlihat bila relevan:

1. Landing: hero, peringatan darurat, KPI, cara kerja, laporan terbaru.
2. Peta dengan filter + marker dan tampilan daftar.
3. Form lapor pada layar mobile, lokasi, foto preview.
4. Detail laporan: alasan skor, status, timeline, pilihan verifikasi.
5. Antrean petugas dan aksi status.
6. Admin: persetujuan/peran dan bobot berjumlah 100.
7. Analitik: grafik, grid wilayah rawan, metode/periode.
8. API docs dan contoh respons JSON.
9. Tentang: batasan, SDGs, bobot dan sumber.

Sembunyikan alamat email akun demo jika screenshot dipublikasikan.
